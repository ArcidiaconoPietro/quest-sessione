Capitolo 4 · giorno 1/12 · libro p. 92 e pp. 115-134

Funzioni che rispettano somme e multipli

Un'applicazione lineare è una funzione tra spazi vettoriali che "va d'accordo" con le due operazioni: l'immagine di una somma è la somma delle immagini, l'immagine di un multiplo è il multiplo dell'immagine.

Il motivo per cui ti interessano: ogni applicazione lineare è una matrice, e viceversa. Così domande come "f è iniettiva?" o "quanto è grande l'immagine?" diventano conti di rango, che sai già fare.

Videolezione

Rifacciamo tutto, un calcolo alla volta

Premi Avvia: sulla lavagna compare un calcolo alla volta e la voce lo spiega. Puoi mettere in pausa, tornare indietro o saltare a una scena. Se la voce non parte, il testo sotto la lavagna dice le stesse cose.

L'idea con un disegno

Cosa fa A al piano

LA: R² → R², LA(x) = A·x. La griglia grigia è il piano dopo la trasformazione: le rette restano rette, le parallele restano parallele, l'origine sta ferma. Il quadratino diventa il parallelogramma viola.

Guarda le frecce: A·e₁ è la prima colonna di A e A·e₂ è la seconda colonna. Prova l'esempio "schiaccia su una retta".

Definizioni e fatti, scritti per intero

Le regole da sapere

Applicazione lineare (p. 115)

f: V → W (V, W spazi vettoriali su K) è lineare se per ogni u, v ∈ V e ogni λ ∈ K:

f(u + v) = f(u) + f(v)    e    f(λ·v) = λ·f(v)

Conseguenza utile per i quiz: f(0) = 0. Se f(0) ≠ 0, f non è lineare (es. f(x, y) = (x + 1, y)). Anche prodotti tra variabili, quadrati, seni… la rendono non lineare.

Matrice ↔ applicazione (Prop. 4.1.19 e Cor. 4.1.7)

Per A ∈ M(m, n, K), LA: Kⁿ → Kᵐ, LA(x) = A·x è lineare. Ogni f: Kⁿ → Kᵐ lineare è LA per un'unica A, e la colonna i di A è f(eᵢ).

perché: facile
Perché la colonna i è A·eᵢ?

eᵢ ha un 1 al posto i e 0 altrove. Nel prodotto riga per colonna ogni riga di A "pesca" solo il suo i-esimo numero. Il risultato è la colonna i.

Più in generale (Prop. 4.1.18): un'applicazione lineare è decisa da cosa fa su una base. Se sai f(v₁), …, f(vn), sai tutto.

Nucleo e immagine (pp. 121-123)

ker f = {v ∈ V : f(v) = 0} ⊆ V e Im f = {f(v) : v ∈ V} ⊆ W sono sottospazi.

f è iniettiva ⇔ ker f = {0} (Prop. 4.2.2). Per LA: ker LA sono le soluzioni di A·x = 0, e Im LA = Span(colonne di A), quindi dim Im LA = rk A (Cor. 4.2.8).

perché: facile
Perché iniettiva vuol dire nucleo nullo?

f(u) = f(v) ⇔ f(u) − f(v) = 0 ⇔ f(u − v) = 0 ⇔ u − v ∈ ker f. Se ker f = {0} allora u − v = 0, cioè u = v.

Teorema della dimensione (Teorema 4.2.9, p. 124)

dim V = dim ker f + dim Im f

a memoria: la formula
L'idea

Le direzioni di V o vengono "schiacciate a zero" (finiscono nel nucleo) o arrivano da qualche parte (fanno l'immagine). Per LA è il conto che sai già: n = (n − rk A) + rk A.

Conseguenze da quiz: se dim V > dim W, f non è iniettiva. Se dim V < dim W, f non è suriettiva. Se dim V = dim W: iniettiva ⇔ suriettiva ⇔ isomorfismo ⇔ (per LA) A invertibile.

Matrice associata (par. 4.3)

B = (v₁, …, vn) base di V, C base di W. La matrice [f]BC ha come colonna j le coordinate di f(vj) rispetto a C. Allora [f(v)]C = [f]BC · [v]B (Prop. 4.3.4).

Rango per righe = rango per colonne (p. 92): ti serve per dire che rk A = rk(tA).

La ricetta, un passo alla volta

Nucleo e immagine di LA

Esempio: A = ${M([[1,1,2],[0,1,1],[1,2,3]])}$, LA: R³ → R³.

Passo 1 · Gauss su A

R3 ← R3 − R1: (1 − 1, 2 − 1, 3 − 2) = (0, 1, 1). Ora R2 e R3 sono uguali: R3 ← R3 − R2 = (0 − 0, 1 − 1, 1 − 1) = (0, 0, 0).

${M([[1,1,2],[0,1,1],[0,0,0]])}$

Pivot nelle colonne 1 e 2: rk A = 2.

Passo 2 · Immagine

Im LA = Span(colonne originali con pivot) = Span((1, 0, 1), (1, 1, 2)). dim Im = 2. Non è suriettiva (2 < 3).

Passo 3 · Nucleo: risolvi A·x = 0 dalla matrice ridotta

Riga 2: y + z = 0, quindi y = −z. Riga 1: x + y + 2z = 0, quindi x = −y − 2z. Sostituisco y = −z: x = −(−z) − 2z = z − 2z = −z. Chiamo z = t: (x, y, z) = (−t, −t, t) = t·(−1, −1, 1). ker LA = Span((−1, −1, 1)), dim ker = 1. Non è iniettiva.

Passo 4 · Controllo col teorema della dimensione

dim ker + dim Im = 1 + 2 = 3 = dim R³ ✓

La ricetta, un passo alla volta

Matrice associata: la derivata

f: R₂[x] → R₂[x], f(p) = p′ (derivata). Base B = C = (1, x, x²).

Passo 1 · Calcola f su ogni vettore della base

f(p) = p′ (derivata). f(1) = 0 (la derivata di una costante è 0), f(x) = 1, f(x²) = 2x.

Passo 2 · Scrivi le coordinate nella base (1, x, x²)

0 = 0·1 + 0·x + 0·x² → (0, 0, 0); 1 = 1·1 + 0·x + 0·x² → (1, 0, 0); 2x = 0·1 + 2·x + 0·x² → (0, 2, 0).

Passo 3 · Mettile in colonna

[f]BB = ${M([[0,1,0],[0,0,2],[0,0,0]])}$

Controllo: p = 3 + 5x + 4x² ha coordinate (3, 5, 4). Matrice per (3, 5, 4): riga 1 = 0·3 + 1·5 + 0·4 = 5, riga 2 = 0·3 + 0·5 + 2·4 = 8, riga 3 = 0. Risultato (5, 8, 0), cioè 5 + 8x. Derivata diretta: p′ = 5 + 2·4x = 5 + 8x ✓. rk = 2, ker f = costanti (dim 1), 1 + 2 = 3 ✓.

Laboratorio

Rango di A = dimensione dell'immagine

Scrivi la matrice di LA. Il laboratorio dà rk A = dim Im LA, le colonne che generano l'immagine e dim ker LA = n − rk A.

Tocca a te · esercizio guidato

A = ${M([[1,2,1],[2,4,0]])}$, LA: R³ → R²

Trova rk A, dim Im, dim ker e una base del nucleo. Di' se LA è iniettiva o suriettiva.

Sul quaderno-formulario

Da scrivere a mano

  • Lineare: f(u + v) = f(u) + f(v), f(λ·v) = λ·f(v). Test veloce: f(0) = 0, niente prodotti o quadrati di variabili.
  • Colonna i di A = A·eᵢ. Ogni f: Kⁿ → Kᵐ lineare è LA.
  • ker LA = soluzioni di A·x = 0. Im LA = Span(colonne). dim Im = rk A.
  • Iniettiva ⇔ ker = {0}. Suriettiva ⇔ Im = W ⇔ rk A = m.
  • dim V = dim ker f + dim Im f.
  • [f]BC: colonna j = coordinate di f(vj) nella base C.
