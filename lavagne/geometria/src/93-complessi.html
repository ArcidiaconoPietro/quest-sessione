Ripasso 3 · costruito sui tuoi errori del 18/11

Numeri complessi senza trappole

Un caso che non sai ancora risolvere

Risolvi z² + 2z + 2 = 0.

Perché con quello che sai non ci riesci

Δ = 2² − 4·1·2 = 4 − 8 = −4 < 0. Con i numeri reali ti fermi: nessun numero reale al quadrato fa −4, quindi "nessuna soluzione". Ma all'esame ti chiedono le soluzioni.

Lo strumento nuovo

I numeri complessi: si aggiunge un numero i con i² = −1. Così anche i negativi hanno radice quadrata e la formula del secondo grado funziona sempre.

Il caso risolto, passo per passo
  1. (2i)² = 2²·i² = 4·(−1) = −4 ⇒ radici di −4: ±2i
  2. z = (−2 ± 2i)/2 = −1 ± i
  3. Verifica z = −1 + i: z² = 1 − 2i + i² = 1 − 2i − 1 = −2i
  4. z² + 2z + 2 = −2i + (−2 + 2i) + 2 = 0 ✓
La formula da usare

i² = −1.   az² + bz + c = 0 ⇒ z = (−b ± w)/(2a), con w² = Δ.

perché: facile, è la stessa formula di sempre, ora la radice esiste

Che casi risolvi così

  • Equazioni di secondo grado con Δ < 0 o con coefficienti complessi.
  • Prodotti e inversi (sempre con i² = −1).
  • Potenze grandi: lì serve De Moivre (scena 4).

Nel quiz c'è quasi sempre una domanda sui complessi. Le radici n-esime le sai già. Gli errori del 18/11 erano: prodotto (i² = −1 dimenticato), inverso (diviso per |z| invece di |z|²), quadrante sbagliato nell'argomento, eiπ = −1, e le equazioni di secondo grado con coefficienti complessi. Qui c'è un esercizio per ognuno.

L'idea con un disegno

Il piano di Gauss: z, z̄, 1/z e z·w

z = a + b·i è il punto (a, b). Guarda in che quadrante cade prima di scrivere l'argomento. Scegli w: moltiplicare per w moltiplica i moduli e somma gli argomenti.

Definizioni e fatti, scritti per intero

Le regole da sapere

Forma algebrica e prodotto

z = a + b·i con a, b ∈ R e i² = −1.

(a + b·i)·(c + d·i) = a·c + a·d·i + b·c·i + b·d·i² = (a·c − b·d) + (a·d + b·c)·i

Scrivi sempre tutti e 4 i pezzi, poi sostituisci i² = −1. È lì che nasce il segno meno.

Coniugato, modulo, inverso

z̄ = a − b·i.   |z| = √(a² + b²).   z·z̄ = a² + b² = |z|² (un numero reale).

z⁻¹ = z̄ / |z|² = (a − b·i) / (a² + b²)

Si divide per |z|² senza radice.

perché: facile
Una riga

z · (z̄ / |z|²) = (z·z̄) / |z|² = |z|² / |z|² = 1.

Forma esponenziale e quadrante

z = r·eiθ = r·(cos θ + i·sin θ) con r = |z| e θ = argomento.

Per trovare θ: 1) guarda i segni di a e b e decidi il quadrante; 2) trova l'angolo con cos θ = a/r e sin θ = b/r; 3) controlla che θ stia nel quadrante giusto.

I: a > 0, b > 0 → θ tra 0 e π/2.  II: a < 0, b > 0 → tra π/2 e π.  III: a < 0, b < 0 → tra π e 3π/2.  IV: a > 0, b < 0 → tra 3π/2 e 2π.

Da sapere: ei·0 = 1, eiπ/2 = i, eiπ = −1, ei3π/2 = −i, ei2π = 1.

eiθ = cos θ + i·sin θ: a memoria
Perché a memoria

È la formula di Eulero; la dimostrazione usa le serie di potenze (Analisi). Si usa come definizione.

Potenze e prodotti in forma esponenziale (De Moivre)

r·eiα · s·eiβ = r·s·ei(α + β)    (r·eiθ)ⁿ = rⁿ·ei·nθ

perché: facile
Le potenze si sommano

eiα·eiβ = eiα + iβ, come per qualsiasi esponenziale.

Radici n-esime (il tuo punto forte)

Le soluzioni di zⁿ = r·eiθ sono zk = ⁿ√r · ei(θ + 2kπ)/n per k = 0, 1, …, n − 1: n punti sui vertici di un poligono regolare.

Equazioni di secondo grado in C

a·z² + b·z + c = 0 con a, b, c ∈ C (a ≠ 0): z = (−b + w) / (2a), dove w sono le due radici quadrate complesse di Δ = b² − 4ac.

In C non c'è mai "Δ < 0 impossibile": per esempio le radici quadrate di −4 sono 2i e −2i. Se i coefficienti sono complessi, calcola le radici di Δ con la forma esponenziale oppure risolvi (x + y·i)² = Δ.

Trucco: spesso conviene riconoscere un quadrato, es. z² − 2i·z − 1 = (z − i)².

Sul quaderno-formulario

Da scrivere a mano

  • Prodotto: 4 pezzi, poi i² = −1.
  • z⁻¹ = z̄ / |z|² (modulo al quadrato, senza radice).
  • Quadrante prima dell'angolo: segni di a e b.
  • eiπ = −1, eiπ/2 = i, ei3π/2 = −i. Alla fine riporta in forma algebrica.
  • (r·eiθ)ⁿ = rⁿ·einθ; radici n-esime: ⁿ√r·ei(θ + 2kπ)/n.
  • 2° grado in C: z = (−b + w)/(2a) con w² = Δ; Δ negativo va bene.
