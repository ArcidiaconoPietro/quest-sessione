Sistemi lineari e Rouché-Capelli

Quasi ogni esercizio di Geometria finisce in un sistema lineare: nuclei, autospazi, intersezioni, coordinate. Qui ripassi il metodo completo e i sistemi con un parametro k, dove c'è la trappola che hai già incontrato: dividere per un'espressione che può valere 0.

L'idea con un disegno

Due rette nel piano: 1, 0 o infinite soluzioni

La retta blu è fissa: x + y = 2. Muovi la retta arancione a·x + b·y = c. Le soluzioni del sistema sono i punti in comune.

Definizioni e fatti, scritti per intero

Le regole da sapere

Forma matriciale

Un sistema di m equazioni in n incognite si scrive A·x = b con A ∈ M(m, n, K), x ∈ Kⁿ, b ∈ Km. La matrice completa è (A | b): A con b aggiunto come ultima colonna.

Se b = 0 il sistema è omogeneo: ha sempre almeno la soluzione x = 0, e le soluzioni formano il sottospazio ker A.

Teorema di Rouché-Capelli

A·x = b ha soluzione se e solo se rk A = rk(A | b). In quel caso le soluzioni dipendono da n − rk A parametri liberi.

• rk A ≠ rk(A | b) → nessuna soluzione (dopo Gauss trovi una riga 0 = numero ≠ 0).
• rk A = rk(A | b) = n → una sola soluzione.
• rk A = rk(A | b) < n → infinite soluzioni, n − rk parametri.

perché: facile
Lettura con le colonne

A·x = x₁·C₁ + … + xn·Cn. Il sistema ha soluzione ⇔ b è combinazione delle colonne ⇔ b ∈ Span(C₁, …, Cn) ⇔ aggiungere b non fa salire il rango. Il numero di parametri è dim ker A = n − rk A.

Sistema quadrato (n equazioni, n incognite)

det A ≠ 0 ⇔ una sola soluzione, qualunque sia b. Con det A = 0 può non esserci soluzione o essercene infinite: bisogna controllare rk(A | b).

Sistemi con parametro: la regola d'oro

Prima di dividere per un'espressione con k (per esempio k − 1), separa il caso in cui vale 0 e studialo a parte. Nel tuo registro errori del 18/11 c'è proprio questa svista.

Metodo veloce per sistemi quadrati: calcola det A in funzione di k. I k con det A ≠ 0 danno una sola soluzione; i (pochi) k con det A = 0 si studiano uno per uno con Gauss.

Sul quaderno-formulario

Da scrivere a mano

  • Rouché-Capelli: soluzioni ⇔ rk A = rk(A | b). Parametri liberi: n − rk A.
  • Quadrato: det A ≠ 0 ⇔ una sola soluzione.
  • Omogeneo: sempre x = 0; soluzioni = ker A.
  • Parametro: mai dividere per k − 1 (o simili) senza aver prima studiato a parte k = 1.
