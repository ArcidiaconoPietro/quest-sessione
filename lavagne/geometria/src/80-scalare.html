Lunghezze e angoli tra vettori

Finora i vettori si potevano solo sommare e moltiplicare per numeri. Il prodotto scalare aggiunge la geometria: quanto è lungo un vettore, che angolo fanno due vettori, quando sono perpendicolari.

Lavoriamo in Rⁿ con il prodotto scalare euclideo (quello standard). Servirà nel capitolo 9 per il teorema spettrale.

Videolezione

Rifacciamo tutto, un calcolo alla volta

Premi Avvia: sulla lavagna compare un calcolo alla volta e la voce lo spiega. Puoi mettere in pausa, tornare indietro o saltare a una scena. Se la voce non parte, il testo sotto la lavagna dice le stesse cose.

L'idea con un disegno

Prodotto scalare, angolo, proiezione

Muovi u (blu) e w (arancione). Il segmento viola è la proiezione di u sulla retta di w. Quando u e w sono perpendicolari, ⟨u, w⟩ = 0 e la proiezione sparisce.

Definizioni e fatti, scritti per intero

Le regole da sapere

Prodotto scalare euclideo su Rⁿ

⟨x, y⟩ = x₁·y₁ + x₂·y₂ + … + xn·yn = tx · y

È un numero (non un vettore). È simmetrico, lineare in ogni argomento e definito positivo: ⟨x, x⟩ > 0 per ogni x ≠ 0.

Norma (lunghezza)

‖x‖ = √⟨x, x⟩ = √(x₁² + … + xn²)

perché: facile
È Pitagora

In R² la freccia (x₁, x₂) è l'ipotenusa di un triangolo rettangolo con cateti |x₁| e |x₂|. In Rⁿ si ripete Pitagora una coordinata alla volta.

Un vettore con ‖x‖ = 1 si dice unitario. Per renderlo unitario: x / ‖x‖ (si "normalizza").

Angolo tra due vettori non nulli

cos θ = ⟨x, y⟩ / (‖x‖ · ‖y‖),   θ ∈ [0, π]

perché: a memoria
Da dove viene

In R² è il teorema del coseno (Carnot). In Rⁿ si usa come definizione dell'angolo, e funziona grazie alla disuguaglianza di Cauchy-Schwarz |⟨x, y⟩| ≤ ‖x‖·‖y‖, che garantisce un numero tra −1 e 1. Ricorda la formula.

Segno di ⟨x, y⟩: positivo ⇒ angolo acuto; zero ⇒ retto; negativo ⇒ ottuso. Perché: ‖x‖ > 0 e ‖y‖ > 0, quindi cos θ ha lo stesso segno di ⟨x, y⟩. In [0, π] il coseno è positivo per θ < π/2, vale 0 per θ = π/2, è negativo per θ > π/2.

Ortogonalità

x e y sono ortogonali (x ⊥ y) se ⟨x, y⟩ = 0. Vettori non nulli a due a due ortogonali sono sempre linearmente indipendenti.

Il conto (con 2 vettori)

⟨v, w⟩ = 0, v ≠ 0, w ≠ 0. Suppongo a·v + b·w = 0. Faccio il prodotto scalare con v: ⟨a·v + b·w, v⟩ = a·⟨v, v⟩ + b·⟨w, v⟩ = a·⟨v, v⟩ + b·0 = a·⟨v, v⟩. Ma è anche ⟨0, v⟩ = 0. Quindi a·⟨v, v⟩ = 0, e ⟨v, v⟩ = ‖v‖² > 0, quindi a = 0. Uguale con w: b = 0. Allora sono indipendenti.

W ⊆ Rⁿ sottospazio. Il suo ortogonale è W⊥ = { v ∈ Rⁿ : ⟨v, w⟩ = 0 per ogni w ∈ W }.

dim W⊥ = n − dim W

In pratica: se W = Span(w₁, …, wk), allora W⊥ è dato dal sistema ⟨v, w₁⟩ = 0, …, ⟨v, wk⟩ = 0. Esempio: W = Span((1, 1, 1)) in R³. v = (x, y, z) ∈ W⊥ ⇔ ⟨(x, y, z), (1, 1, 1)⟩ = 0 ⇔ x·1 + y·1 + z·1 = 0 ⇔ x + y + z = 0. Quindi W⊥ = { x + y + z = 0 }.

dim: facile
Perché

W⊥ è il nucleo della matrice k × n con righe w₁, …, wk (base di W), che ha rango k = dim W. Teorema della dimensione: n − k.

Proiezione ortogonale su una retta

projw(v) = ( ⟨v, w⟩ / ⟨w, w⟩ ) · w

È la "ombra" di v sulla retta Span(w). Il resto v − projw(v) è ortogonale a w.

perché: facile
Il conto

Cerco c con v − c·w ⊥ w: ⟨v − c·w, w⟩ = 0 ⇒ ⟨v, w⟩ − c·⟨w, w⟩ = 0 ⇒ c = ⟨v, w⟩ / ⟨w, w⟩.

Gram-Schmidt

Da una base (v₁, …, vk) ottieni una base ortogonale (w₁, …, wk) dello stesso spazio:

w₁ = v₁
w₂ = v₂ − (⟨v₂, w₁⟩/⟨w₁, w₁⟩)·w₁
w₃ = v₃ − (⟨v₃, w₁⟩/⟨w₁, w₁⟩)·w₁ − (⟨v₃, w₂⟩/⟨w₂, w₂⟩)·w₂

Ogni volta togli le proiezioni sui w già trovati. Per una base ortonormale dividi alla fine ogni wi per ‖wi‖.

Matrici ortogonali

A ∈ M(n, n, R) è ortogonale se tA · A = In, cioè A⁻¹ = tA. Equivale a: le colonne di A sono una base ortonormale di Rⁿ.

Allora det A = ±1 e A conserva lunghezze e angoli (rotazioni e riflessioni).

La ricetta, un passo alla volta

Base ortonormale di W = { x + y + z = 0 } ⊆ R³

Passo 1 · Una base qualsiasi di W

x = −y − z. Con y = 1, z = 0: v₁ = (−1, 1, 0). Con y = 0, z = 1: v₂ = (−1, 0, 1).

Passo 2 · w₁ = v₁

w₁ = (−1, 1, 0), ⟨w₁, w₁⟩ = 1 + 1 + 0 = 2.

Passo 3 · Togli a v₂ la proiezione su w₁

⟨v₂, w₁⟩ = 1 + 0 + 0 = 1. w₂ = (−1, 0, 1) − (1/2)·(−1, 1, 0) = (−1/2, −1/2, 1).

Controllo: ⟨w₂, w₁⟩ = 1/2 − 1/2 + 0 = 0. ✓

Passo 4 · Normalizza

‖w₁‖ = √2, ‖w₂‖ = √(1/4 + 1/4 + 1) = √(3/2).

Base ortonormale: ( (1/√2)·(−1, 1, 0),  √(2/3)·(−1/2, −1/2, 1) ).

Trucco: puoi moltiplicare w₂ per 2 prima di normalizzare, (−1, −1, 2), e i conti vengono più puliti: (1/√6)·(−1, −1, 2).

Tocca a te · esercizio guidato

Gram-Schmidt su v₁ = (1, 1, 0), v₂ = (1, 0, 1)

Trova una base ortogonale (w₁, w₂) di U = Span(v₁, v₂) ⊆ R³.

Esercizi da solo

Adesso senza aiuti

Sul quaderno-formulario

Da scrivere a mano

  • ⟨x, y⟩ = Σ xi·yi (un numero). ‖x‖ = √⟨x, x⟩.
  • cos θ = ⟨x, y⟩ / (‖x‖·‖y‖) (a memoria). ⟨x, y⟩ = 0 ⇔ ortogonali.
  • projw(v) = (⟨v, w⟩/⟨w, w⟩)·w.
  • Gram-Schmidt: wk = vk − somma delle proiezioni di vk sui w già trovati. Poi normalizza.
  • W⊥: sistema ⟨v, wi⟩ = 0. dim W⊥ = n − dim W.
  • Ortogonale: tA·A = I, A⁻¹ = tA, colonne ortonormali, det A = ±1.
