Gli integrali indefiniti

Derivare: da f trovo f′. Integrare è il viaggio al contrario: ti do f, trovi una funzione F che derivata dà f. F si chiama primitiva.

∫ f(x) dx = F(x) + C   significa   F′(x) = f(x)

A cosa serve: è il passo che ti serve per calcolare aree (capitolo 14) e per risolvere le equazioni differenziali (capitolo 15). All'esame c'è quasi sempre un integrale da calcolare.

Perché + C · prima guardiamo facile

Tante primitive, tutte "parallele"

Se F è una primitiva, anche F + 1, F − 3, F + C vanno bene: la derivata di una costante è 0. Nel grafico: sposta C, la curva sale e scende, ma nel punto x₀ la pendenza resta la stessa, e vale proprio f(x₀).

E sono le uniche: due primitive della stessa f hanno differenza con derivata 0, quindi costante (conseguenza di Lagrange, capitolo 11). Vale su un intervallo.
Integrali immediati a memoria sono le derivate lette al contrario

La tabellina

∫ xᵃ dx = xa+1a + 1 + C   (a ≠ −1)
∫ 1x dx = ln |x| + C
∫ eˣ dx = eˣ + C
∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C
∫ 11 + x² dx = arctan x + C
∫ 1cos² x dx = tan x + C
∫ 1√(1 − x²) dx = arcsin x + C

Linearità facile: ∫ (a f + b g) dx = a ∫ f dx + b ∫ g dx. Il trucco per controllare sempre: deriva il risultato. Se torna f, è giusto.

  1. ∫ x² dx con la regola (a = 2): x2+1/(2 + 1) = x³/3 + C. Controllo: (x³/3)′ = 3x²/3 = x² ✓
  2. ∫ sin x dx = −cos x + C. Controllo: (−cos x)′ = −(−sin x) = sin x ✓ (per questo c'è il meno)
  3. ∫ √x dx, cioè a = 1/2: x3/2/(3/2) = (2/3) x3/2 + C. Controllo: (2/3) · (3/2) x1/2 = √x ✓
  4. ∫ (4x³ − 6x + 5) dx, pezzo per pezzo: 4 · x⁴/4 − 6 · x²/2 + 5x = x⁴ − 3x² + 5x + C. Controllo: 4x³ − 6x + 5 ✓

Immediati "generalizzati": se dentro c'è g(x) e fuori c'è g′(x), è la catena al contrario. ∫ g′(x)/g(x) dx = ln |g(x)| + C, ∫ g′(x) eg(x) dx = eg(x) + C. Esempio: ∫ 2x/(x² + 1) dx = ln(x² + 1) + C.

  1. Chi è g: sotto c'è g(x) = x² + 1
  2. La sua derivata: g′(x) = 2x, ed è proprio quello che c'è sopra
  3. Quindi è g′/g: ∫ g′/g dx = ln |g| + C = ln(x² + 1) + C (x² + 1 è sempre positivo, il modulo si toglie)
  4. Controllo con la catena: (ln(x² + 1))′ = 1/(x² + 1) · 2x = 2x/(x² + 1) ✓
Metodo 1 è la catena al contrario

Sostituzione

Pongo t = g(x), quindi dt = g′(x) dx. Riscrivo tutto con t, integro, rimetto x.

∫ cos(3x) dx:   t = 3x, dt = 3 dx, dx = dt/3  →  ∫ cos t · dt/3 = (1/3) sin t + C = (1/3) sin(3x) + C

Regola pratica: con f(ax + b) dentro, il risultato è F(ax + b)/a. Esempio: ∫ e2x dx = e2x/2 + C.

  1. Controllo il primo con la catena: ((1/3) sin(3x))′ = (1/3) · cos(3x) · 3 = cos(3x) ✓
  2. Il secondo, con la sostituzione: t = 2x, dt = 2 dx, dx = dt/2 → ∫ eᵗ dt/2 = eᵗ/2 + C = e2x/2 + C
  3. Controllo: (e2x/2)′ = e2x · 2/2 = e2x ✓
  4. Un esempio senza regola pratica, ∫ x · cos(x²) dx: t = x², dt = 2x dx, quindi x dx = dt/2 → ∫ cos t · dt/2 = (1/2) sin t + C = (1/2) sin(x²) + C
  5. Controllo: ((1/2) sin(x²))′ = (1/2) cos(x²) · 2x = x cos(x²) ✓
Metodo 2 formula a memoria il perché è facile

Per parti

∫ f(x) g′(x) dx = f(x) g(x) − ∫ f′(x) g(x) dx

Perché (una riga): (f g)′ = f′g + f g′ (regola del prodotto). Integro tutti e due i lati: f g = ∫ f′g dx + ∫ f g′ dx. Sposto un pezzo e ho la formula.

Chi scegliere come f (da derivare): quella che derivata diventa più semplice. Polinomi: da derivare (x → 1). eˣ, sin, cos: da integrare (restano uguali). ln x e arctan x: sempre da derivare (diventano 1/x e 1/(1 + x²)).

∫ ln x dx = ∫ ln x · 1 dx: f = ln x, g′ = 1 → x ln x − ∫ (1/x) · x dx = x ln x − x + C
  1. Scelgo: f = ln x (da derivare), g′ = 1 (da integrare)
  2. Calcolo i pezzi: f′ = 1/x, g = ∫ 1 dx = x
  3. Formula f g − ∫ f′ g: ln x · x − ∫ (1/x) · x dx
  4. Semplifico dentro: (1/x) · x = 1, quindi − ∫ 1 dx = −x
  5. Risultato: x ln x − x + C
  6. Controllo: (x ln x − x)′ = (1 · ln x + x · 1/x) − 1 = ln x + 1 − 1 = ln x ✓
Metodo 3 · funzioni razionali da capire con lo schema

Fratti semplici

Per ∫ P(x)/Q(x) dx con polinomi:

1 · Se grado di P ≥ grado di Q

Prima faccio la divisione tra polinomi: P/Q = quoziente + resto/Q.

2 · Scompongo Q

Radici distinte: 1(x − a)(x − b) = Ax − a + Bx − b. Trovo A e B facendo il denominatore comune e uguagliando i numeratori.

3 · Integro i pezzi

∫ A/(x − a) dx = A ln |x − a| + C. Se Q ha radice doppia: ∫ 1/(x − a)² dx = −1/(x − a) + C. Se Q non ha radici (Δ < 0): si arriva a un arctan.

Esempio con tutti i calcoli: ∫ 1x² − 1 dx.

  1. Gradi: sopra 0, sotto 2: niente divisione
  2. Scompongo sotto: x² − 1 = (x − 1)(x + 1)
  3. Scrivo i fratti: 1(x − 1)(x + 1) = Ax − 1 + Bx + 1
  4. Denominatore comune: 1 = A(x + 1) + B(x − 1)
  5. Metto x = 1: 1 = A · 2 + B · 0 → A = 1/2
  6. Metto x = −1: 1 = A · 0 + B · (−2) → B = −1/2
  7. Integro i pezzi: (1/2) ln |x − 1| − (1/2) ln |x + 1| + C
  8. Controllo in x = 2: la funzione vale 1/(4 − 1) = 1/3; la derivata del risultato vale (1/2) · 1/(2 − 1) − (1/2) · 1/(2 + 1) = 1/2 − 1/6 = 3/6 − 1/6 = 2/6 = 1/3 ✓

Sul quaderno-formulario

Da scrivere a mano

  • ∫ f dx = F + C ⇔ F′ = f. Controllo: derivo il risultato.
  • Tabellina: xᵃ → xa+1/(a + 1); 1/x → ln|x|; eˣ → eˣ; sin → −cos; cos → sin; 1/(1 + x²) → arctan x; 1/cos² x → tan x.
  • g′/g → ln|g|; f(ax + b) → F(ax + b)/a.
  • Per parti: ∫ f g′ = f g − ∫ f′ g. Derivo polinomi, ln, arctan; integro eˣ, sin, cos.
  • Razionali: divisione se serve → A/(x − a) + B/(x − b) → ln.
